# PG29 - Yeison Munoz - VFS - Mobile Dev 4 - Assignment 1

This project consists in a ball mobile game using gyroscope and touch features. Player tilts the phone to move the ball around the board. The goal is to collect 5 gems before the timer reaches 0.

Chosen native feature: **Touch input**.

The player can hold one finger on the screen to create a temporary Touch Magnet on the board. The ball is pulled toward the touched world position. The magnet has limited charge and recharges when the player stops touching the screen.

## Controls
- Tilt phone: move the ball.
- Hold one finger on the screen: activate Touch Magnet.
- Release touch: magnet turns off and recharges.
- Start button: begins the game.
- Restart button: reloads the level without closing the app.
